# Testzugänge

Für die Abgabe und zum Testen gelten folgende Standardpasswörter.

| Rolle | Passwort |
| --- | --- |
| Bediener | bediener123 |
| Technik | technik123 |
| Admin | admin123 |

Beim Login wird die Rolle ausgewählt. Der Benutzername ist frei wählbar. Die Passwörter können per Umgebungsvariable (`PRINTFARM_PW_BEDIENER`, `PRINTFARM_PW_TECHNIK`, `PRINTFARM_PW_ADMIN`) überschrieben werden.
